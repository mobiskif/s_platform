# Живое фото — говорящий аватар (Android)

Чат-окно: всё, что вы напишете, произносит ваше фото — нижняя часть лица опускается в такт словам,
между губами появляется рот, моргание, лёгкое покачивание головы.

* Готовый файл: `dist/richelieu.apk` (подписан отладочным ключом; Android 5.0+).
* Фото: `art/make_photo.py <photo.png> src/main/assets` → `assets/face.jpg` + `assets/avatar.properties`
  (ориентиры лица подобраны вручную под конкретный снимок; для другого фото поправьте константы в скрипте).
  Исходные `input/` в git не хранятся.
* Голос — системный синтезатор речи Android (TextToSpeech); кнопка «Голос»: тембр, темп, выбор голоса.
  Язык по тексту: кириллица → русский, французские слова → французский, иначе английский.
* Пересборка: `./build.sh` (aapt, javac, dx, zipalign, apksigner; см. заголовок скрипта).
