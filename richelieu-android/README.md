# Ришельё — говорящий кардинал (Android)

Чат-окно: всё, что вы напишете, произносит анимированный портрет кардинала Ришельё —
рот двигается в такт словам, моргание, брови поднимаются на «!» и «?».

* Готовый файл: `dist/richelieu.apk` (подписан отладочным ключом; Android 5.0+).
  Установка: скопировать на телефон → открыть → разрешить «установку из неизвестных источников».
* Лицо — ваше фото (`art/make_photo.py` → `assets/face.png`) в костюме кардинала (`art/make_art.py` → `assets/richelieu.txt`):
  челюсть опускается и открывает рот в такт речи, моргание, покачивание головы.
  Исходные `input/photo.png` и `input/voice.m4a` в git не хранятся (`.gitignore`).
* Голос — системный синтезатор речи Android (TextToSpeech): низкий тембр и медленный темп
  (кнопка «Голос»: тембр, темп и выбор из установленных голосов; значения по умолчанию подобраны по записи: основной тон ~92 Гц). Язык определяется по тексту: кириллица → русский,
  французские слова/буквы → французский, иначе английский. Нужны установленные голоса
  в настройках Android («Службы речи Google» и т.п.).
* Пересборка: `./build.sh` (aapt, javac, dx, zipalign, apksigner; см. заголовок скрипта).
* Превью лица: `python3 art/preview.py src/main/assets/richelieu.txt out.png 0.8 0`
